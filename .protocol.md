## Critical rules (FRC-Test_Code)

- Build from the specific sub-project directory (e.g., `cd Motor_System && ./gradlew build`); always set JAVA_HOME to WPILib JDK 17: `JAVA_HOME="C:/Users/Public/wpilib/2026/jdk" ./gradlew build`. System Java is Java 8. ([[wpilib-build-env]])
- `_common` workflow is COPY-not-import: update `_common` first, then propagate to all consuming sub-projects and verify builds. Never import from `_common` directly.
- `Motor_Test_backup` is historical backup only — use Motor_System for any new motor abstraction work.
- Wheeled_Base PathPlanner controller is `PPLTVController` (differential drive), NOT `PPHolonomicDriveController`. Mixing these up breaks path following.
- No secrets or credentials live in this repo. No secret-scan exceptions.
