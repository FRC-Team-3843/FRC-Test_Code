## Sub-projects

- **Motor_System** — active motor abstraction library with config-driven setup, SysId, Elastic dashboard layout generation; replaces older Motor_Test (which is now `Motor_Test_backup`).
- **Swerve_Base** — YAGSL-based swerve drive reference (PathPlanner + PhotonVision scaffold).
- **Mecanum_Base** — Mecanum drive reference (IO abstraction, JSON motor/gyro config).
- **Wheeled_Base** — Tank/arcade drive reference (IO abstraction, JSON motor/gyro config; uses `PPLTVController` for PathPlanner, NOT `PPHolonomicDriveController`).
- **_common** — copyable canonical snapshots of shared code; `_common/motor_system` is a legacy snapshot, prefer Motor_System internal library modules.
(source: README.md, .project-context.md, .standards.md)

## Build environment

Build from the specific sub-project directory: `cd Motor_System && ./gradlew build`. Requires JAVA_HOME set to WPILib JDK 17 — see [[wpilib-build-env]]. Java 8 (system default) will fail. (source: .standards.md Build and Deploy)

## Architecture patterns

All projects follow WPILib 2026 command-based framework. Test projects use **verbose telemetry** via `LoggingConstants` flags — trim before competition deployment. Vision and auto features are disabled by default via Constants flags. JSON files in `src/main/deploy` for runtime hardware config (avoids recompilation during hardware swaps). (source: .standards.md)

## Motor health testing (Motor_System)

MotorHealthTest runs five phases: BREAKAWAY (ramp 0–25% to detect stiction), STARTUP (resistance estimation via V/I), STEADY_STATE (Kv = RPM/Volt), COAST_DOWN (15s timeout added), TEMP_MONITOR (45s post-test; button release still produces report). Health score ≥80 = Grade A/B. (source: .changelog.md 2026-01-31/2026-01-31)
